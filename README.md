Diese App ist dazu gedacht die Erstellung von Gruppen fürs WvW in Guildwars 2
von bis zu 50 Personen in max 15 Gruppen mit einer maximalen Größe von 10 Personen je Gruppe zu planen.
Dazu können Builds als Elitespezialisierung ausgewählt werden und entsprechende Links gespeichert werden 
(z.B. https://snowcrows.com/builds/wvw oder https://en.gw2skills.net/editor/) achtet an dieser Stelle bevor ihr auf eine Verlinkung klickt auf die Linkadresse unten in der App.
Mit exportieren kann ein Jason-File generiert werden und an andere geteilt werden.

Diese App ist unter Nutzung von KI erstellt wurden.
